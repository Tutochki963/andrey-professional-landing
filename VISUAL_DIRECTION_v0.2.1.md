# VISUAL DIRECTION v0.2.1 — Warm Systems Portfolio

**Статус:** active visual direction for P0 iteration  
**Основание:** `VISUAL_QA_v0.2.md` + visual feedback after browser review

## Главная коррекция

Предыдущая палитра была слишком холодной, кислотно-бирюзовой и психологически близкой к интерфейсу мониторинга / кибербезопасности. Для персонального профессионального лендинга это создаёт лишнюю дистанцию.

Новая задача — сохранить технологичность, но добавить **доверие, глубину, спокойствие и готовность к сотрудничеству**.

Ключевое ощущение:

**calm competence · human trust · engineering depth · rational motion · evidence**

## Палитра

Базовая среда:

- `#0D1115` — глубокий графит;
- `#121922` — объёмный сине-графитовый слой;
- `#18222B` — поверхности и system panels.

Текст:

- `#EEF1F2` — основной мягкий белый;
- `#CBD3D8` — secondary;
- `#A7B3BB` — muted.

Акценты:

- `#8FB7C9` — спокойный blue-grey / trust accent;
- `#8FAE9E` — приглушённый sage для подтверждения / status;
- `#C5B58F` — тёплый sand / human-business accent.

Запрещено:

- яркий neon mint;
- ядовитый cyan glow;
- большие кислотные градиенты;
- зелёные подсветки в стиле security console.

## Объём

Объём создаётся не свечением, а сочетанием:

- нескольких очень мягких radial-gradient слоёв;
- разницы светлоты поверхностей;
- тонких border highlights;
- мягких внутренних теней;
- локальных elevation shadows;
- лёгких directional gradients.

## Рациональная динамика

Динамика должна показывать движение работы:

`signal → diagnosis → design → implementation → verification → result`

Использовать:

- направляющие линии;
- последовательные узлы;
- смещение уровней;
- изменение тональности по ходу процесса;
- hover как подтверждение интерактивности.

Не использовать движение ради эффекта.

## AI-STUDIO

Pipeline визуально делится на зоны:

- `QUALIFY`
- `UNDERSTAND & DESIGN`
- `DELIVER`
- `VERIFY & DECIDE`

Cross-cutting layers должны восприниматься как rails, проходящие через систему.

## Contact

Контактный блок должен стать более тёплым и приглашать к действию, но не превращаться в lifestyle-секцию.

Целевая контактная архитектура:

**Primary:** Email  
**Professional:** LinkedIn · Telegram  
**Evidence / presence:** GitHub  
**Optional:** Instagram · YouTube

Не создавать фиктивные ссылки. До получения публичных адресов активным остаётся только подтверждённый канал.

## Критерий

Страница должна перестать ассоциироваться с SOC/security dashboard и начать восприниматься как современное инженерно-деловое портфолио человека, с которым хочется обсуждать задачу.
